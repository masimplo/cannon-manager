    Quick actions

    Open printer's own web page

    Fix faded or streaky prints

    1. Print a nozzle check. Look at the pattern: every line should be complete, with no gaps.
    2. If lines are missing, run a cleaning and print another nozzle check.
    3. Still missing after two cleanings? Turn the printer off for at least 24 hours, then check again. If it still fails, run a deep cleaning from the printer's own panel (Setup → Maintenance → Deep Cleaning); it uses much more ink, so use it sparingly.
    4. If straight lines look jagged or colours are offset, run a print head alignment.

    Advanced: send a raw BJL command

    Sends one line inside a Canon BJL control block over port 9100. Only use commands you know your printer supports; unknown commands are normally ignored, but there is no guarantee.

    Print a file

    Images (JPEG, PNG, HEIC, TIFF, GIF) and single-page PDFs. Other files are converted to JPEG on this Mac first.

    Colour test page

    Prints solid K/C/M/Y/R/G/B bars, gradient ramps, a fine line grid and checkerboards on one A4 page. Use it to spot banding, missing colours, and misalignment in normal printing (the nozzle check tests the head directly).
